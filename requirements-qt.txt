# MinbarLive - Qt GUI dependencies (issue #44 migration, work in progress)
#
# Install alongside requirements.txt to run the PySide6 GUI tree (gui_qt/).
# Kept separate while the shipping GUI is still CustomTkinter, so ordinary
# users and CI do not download Qt.
#
# PySide6-Essentials, NOT PySide6: the full package pulls PySide6-Addons, and
# a full install measures 634 MB on disk with Qt6WebEngineCore.dll alone at
# 195 MB (an entire Chromium we never use). Essentials carries QtCore, QtGui
# and QtWidgets, which is all gui_qt/ imports — QML/QtQuick was deliberately
# rejected, see the module docstring in gui_qt/subtitle_window.py.
#
# MinbarLive is AGPL-3.0, so Qt's LGPL imposes no practical constraint beyond
# shipping the Qt LGPL notice.
PySide6-Essentials==6.11.1
